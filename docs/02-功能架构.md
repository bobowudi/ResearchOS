## 各层详细说明

### 1. 数据层

负责多源数据的接入、清洗和标准化。

| 模块 | 功能 | 输入 | 输出 |
|------|------|------|------|
| 问卷数据连接器 | 对接主流问卷平台 API，导入结构化问卷结果 | 问卷平台 API / CSV | 标准化问卷记录 |
| 访谈数据处理器 | 音频转文字、访谈记录解析 | 音频文件 / 文本记录 | 结构化访谈段落 |
| 舆情数据采集器 | 社交媒体、论坛、评论区数据采集 | 平台 API / 爬虫 | 标准化舆情条目 |
| 行业报告解析器 | PDF/文档解析，关键论点提取 | PDF / Word / 网页 | 结构化论点片段 |
| 企业数据连接器 | 对接企业内部数据库/BI系统 | 数据库 / API | 标准化业务指标 |

### 2. 语义层

将不同来源、不同格式的数据映射到统一的语义空间。

| 模块 | 功能 |
|------|------|
| 实体抽取 | 从非结构化文本中识别品牌、产品、人物、事件等实体 |
| 主题聚类 | 将来自不同数据源的内容按主题自动归类 |
| 情感分析 | 识别文本中的情感倾向和强度 |
| 关系映射 | 建立实体之间的关联关系（品牌-属性、产品-评价等） |
| 研究语义层 | 统一语义空间，使不同来源的证据可以被对齐和比较 |

### 3. 推理层

基于语义层的结构化信息进行推理和分析。

| 模块 | 功能 |
|------|------|
| 证据聚合 | 将来自不同数据源的相关证据汇聚到同一议题下 |
| 冲突检测 | 识别不同数据源之间的矛盾信号，标注冲突点 |
| 置信度评估 | 基于数据源质量、样本量、时效性等因素评估证据可信度 |
| 模式识别 | 发现跨数据源的趋势、异常和机会 |

### 4. 决策层

将推理结果转化为可执行的决策建议。

| 模块 | 功能 |
|------|------|
| 决策卡生成 | 基于证据自动生成结构化决策建议，含正反证据和置信度 |
| 行动项派生 | 从决策卡中提取具体可执行的行动任务 |
| 风险评估 | 评估每个决策方向的潜在风险和不确定性 |
| 优先级排序 | 基于影响力、紧迫性、可行性对决策和行动排序 |

### 5. 闭环层

追踪决策执行效果，形成学习闭环。

| 模块 | 功能 |
|------|------|
| 执行追踪 | 跟踪行动项的执行状态和进度 |
| 结果度量 | 对比行动前后的关键指标变化 |
| 模型校正 | 基于执行结果反馈，优化推理和决策模型 |
| 知识沉淀 | 将验证过的决策模式沉淀为组织知识资产 |

### 6. 用户交互层

| 模块 | 功能 |
|------|------|
| 议题工作台 | 创建和管理研究议题，关联证据和决策 |
| 证据浏览器 | 浏览、筛选、标注来自各数据源的证据 |
| 决策看板 | 查看决策卡、对比方案、做出选择 |
| 行动追踪面板 | 管理行动项、更新进度、记录结果 |
| AI 对话助手 | 自然语言交互，随时提问、获取分析、生成决策建议 |

## 数据流

```
用户提出议题
    │
    ▼
系统从多源数据中检索相关证据
    │
    ▼
语义层对齐 + 推理层分析
    │
    ▼
生成决策卡（含正反证据、置信度、风险）
    │
    ▼
用户审阅 → 采纳/修改/拒绝
    │
    ▼
派生行动项 → 分配执行
    │
    ▼
追踪结果 → 反馈校正 → 知识沉淀
    │
    ▼
下一轮决策（闭环）
```
