# 调研决策系统 — 产品定义文档

## 一、产品名称

**ResearchOS** — 多源证据驱动的 AI 调研决策系统

## 二、一句话定位

我们要做的是一个能把问卷、访谈、舆情等零散研究信息自动整合、分析并直接转成可执行决策建议的 AI 调研决策系统，帮助企业更快看清问题、做对动作、拿到结果。

## 三、我们要解决的问题

### 现状痛点

1. **证据碎片化**：问卷数据在一个系统、访谈记录在另一个系统、舆情在第三个系统，决策者无法看到全貌
2. **从洞察到行动断裂**：研究团队输出报告后，决策者不知道该做什么、怎么做、做了之后效果如何
3. **决策缺乏闭环**：做了决策之后没有追踪机制，无法知道决策是否正确，也无法积累组织决策智慧
4. **研究价值被低估**：大量研究成果沉睡在 PPT 和 PDF 中，无法被复用和检索

### 核心洞察

市场上不缺"看数据"的工具（BI），不缺"做调研"的工具（问卷平台），缺的是把**研究证据**转化为**经营行动**并**追踪结果**的系统。

## 四、目标用户

| 角色 | 核心诉求 | 使用场景 |
|------|---------|---------|
| 品牌/市场负责人 | 基于多源数据做品牌决策 | 品牌定位、传播策略、竞品应对 |
| 产品经理 | 基于用户研究做产品决策 | 功能优先级、用户体验优化 |
| 研究/洞察团队 | 提升研究成果的影响力和复用率 | 研究项目管理、知识沉淀 |
| 企业高管 | 快速获取决策依据 | 战略规划、投资决策 |

## 五、核心价值链

```
决策 → 认知 → 洞察 → 行动 → 回看
```

不是传统的 `数据 → 图表 → 报告`，而是：

- **决策**：明确当前要解决的经营/品牌/产品问题（Issue）
- **认知**：汇集多源证据形成结构化认知（Evidence → Decision Card）
- **洞察**：AI 辅助发现证据中的模式、冲突和机会
- **行动**：输出可执行的行动项（Action Item），分配责任人和截止日期
- **回看**：追踪行动结果，形成闭环学习（Review Result）

## 六、与现有产品的差异

### 对比 BI 工具（Power BI / Tableau / ThoughtSpot）

- BI 工具面向**结构化数据**，我们面向**多源研究证据**（含非结构化数据）
- BI 工具输出**图表和看板**，我们输出**决策卡和行动项**
- BI 工具止步于"看见"，我们延伸到"行动"和"回看"

### 对比调研平台（Qualtrics / 问卷星）

- 调研平台止步于**数据采集和基础分析**
- 我们从调研结果出发，融合多源数据，走向**决策和行动**

### 对比咨询报告

- 咨询报告是**一次性交付物**
- 我们是**持续运转的决策引擎**，证据持续更新，决策持续迭代

## 七、独特产品力：多源证据融合

| 数据源 | 类型 | 融合方式 |
|--------|------|---------|
| 问卷数据 | 结构化 | 统计分析 + 语义提取 |
| 深度访谈 | 非结构化 | NLP 编码 + 主题聚类 |
| 社媒/舆情 | 半结构化 | 情感分析 + 趋势识别 |
| 行业报告 | 非结构化 | 关键论点提取 + 引用标注 |
| 企业内部数据 | 结构化 | 指标关联 + 异常检测 |
| 历史研究项目 | 混合 | 知识图谱 + 相似性检索 |

## 八、核心对象模型

系统围绕 5 个核心对象运转：

1. **Issue（议题）**：当前要解决的商业问题
2. **Evidence（证据）**：来自各数据源的支撑/反对信息，标注来源、可信度、时效性
3. **Decision Card（决策卡）**：基于证据形成的结构化决策建议，包含正反证据、置信度、风险提示
4. **Action Item（行动项）**：从决策卡派生的具体执行任务，含责任人、截止日期、预期指标
5. **Review Result（回看结果）**：行动执行后的效果追踪，反馈回模型校正

## 九、关键设计原则

### ADR（架构决策记录）

| 决策 | 选择 | 理由 |
|------|------|------|
| 以决策对象为中心 vs 以指标看板为中心 | 决策对象 | 用户最终需要的是"做什么"，不是"看什么" |
| 语义融合层 vs 仅 ETL 汇总 | 语义融合 | 非结构化数据无法用传统 ETL 处理 |
| 允许冲突证据并存 vs 强制单一结论 | 允许冲突 | 真实决策场景中信息本就矛盾，隐藏冲突是危险的 |
| 执行反馈参与模型校正 vs 归档了事 | 反馈校正 | 闭环是产品核心价值，不闭环就是又一个报告工具 |

## 十、成功指标

| 指标 | 定义 | 目标 |
|------|------|------|
| 决策卡采纳率 | 被标记为"已采纳"的决策卡 / 总生成决策卡 | > 40% |
| 行动项完成率 | 已完成行动项 / 总派生行动项 | > 60% |
| 证据复用率 | 被引用超过 1 次的证据 / 总证据数 | > 30% |
| 决策周期缩短 | 使用系统后的平均决策周期 vs 使用前 | 缩短 50% |
| 用户周活跃率 | 每周至少登录 1 次的用户 / 总用户 | > 50% |
